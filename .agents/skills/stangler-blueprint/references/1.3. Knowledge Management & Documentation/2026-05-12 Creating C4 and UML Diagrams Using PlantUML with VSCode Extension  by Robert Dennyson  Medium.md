WebSync metadata title: Creating C4 and UML Diagrams Using PlantUML with VSCode Extension | by Robert Dennyson | Medium url: https://medium.com/@robertdennyson/creating-c4-and-uml-diagrams-using-plantuml-with-vscode-extension-90032a21ec43 date: 2026-05-12T16:15:56.816Z parsing method: defuddle Sitemap When designing software systems, it’s essential to have a clear and maintainable visual representation of your architecture. The C4 model offers a hierarchy of diagrams (Context, Container, Component, and Code) that help describe the system from different levels of abstraction. Alongside C4, UML diagrams — such as Class, Sequence, and ER diagrams — are invaluable for providing detailed technical views of the system. PlantUML, a text-based diagramming tool, combined with Visual Studio Code (VSCode), offers an effective way to create and maintain these diagrams. In this article, we’ll demonstrate how to create C1 (Context), C2 (Container), C3 (Component), and C4 (Code) diagrams, along with Class, Sequence, and Entity-Relationship (ER) diagrams, using a CRM Order Management System as our example. Setting Up PlantUML with VSCode Before we create the diagrams, let’s ensure the environment is set up correctly. Step 1: Install the PlantUML Extension for VSCode Open VSCode. Go to the Extensions panel (Ctrl+Shift+X). Search for PlantUML and click Install. Step 2: Install Required Dependencies Java Runtime Environment (JRE): PlantUML requires JRE to run. Optionally, install Graphviz to improve diagram rendering. Step 3: Saving Your Diagram in VSCode Create a new file in VSCode with the .puml extension (e.g., crm_order_management.puml). Paste your PlantUML code (e.g., the Archimate diagram or any other diagram) into the file. Save the file (Ctrl + S or File -> Save). Preview the Diagram Make sure you have the PlantUML extension installed in VSCode. If not, follow these steps: Open the Extensions panel (Ctrl + Shift + X). Search for PlantUML. Click Install. To preview the diagram: Open your .puml file in VSCode. Press Alt + D (the default shortcut for previewing PlantUML diagrams). A preview of the diagram will be generated in a separate window within VSCode. Alternatively: Right-click on the .puml file and select "Preview Diagram" from the context menu. Export the Diagram You can export your PlantUML diagram to different formats like PNG, SVG, or PDF. To export your diagram: Right-click within the open .puml file and select "Export Current Diagram". Choose the format you want to export the diagram as (e.g., PNG, SVG, PDF). Select a location on your machine to save the exported diagram. Alternatively, use the command palette: Press Ctrl + Shift + P to open the command palette. Search for “PlantUML: Export Current Diagram” and select it. Choose your export format and destination. Export Using a Shortcut You can also use shortcuts to directly export diagrams: Alt + Shift + D for PNG. Alt + Shift + S for SVG. Alt + Shift + P for PDF. Configuring PlantUML for External Rendering If your diagram preview is slow or fails to render, you may need to install Graphviz for rendering complex diagrams, especially when exporting to formats like PNG or SVG. You can install Graphviz from its official website here. Once Graphviz is installed, VSCode will automatically use it to enhance diagram rendering. If you encounter any issues, you can configure the path to Graphviz by updating the plantuml.graphvizDot setting in VSCode's settings. Use Case: CRM Order Management System Overview The CRM Order Management System is a software platform designed to handle customer orders, manage product inventory, process payments, and track the interaction with external systems such as supplier management platforms. The system provides an interface for customers to place orders and manage their profiles. Core Features Order Placement and Tracking: Customers can place orders via a web application and track them in real-time. Payment Processing: The system integrates with an external payment gateway to securely process payments. Supplier Interaction: Orders are sent to external supplier systems for fulfillment. Product and Inventory Management: Products are managed within the system, and their availability is updated when an order is placed. Architecture Components Web Application: The user interface for customers to interact with the system. API: Handles business logic and interactions with external services. Database: Stores customer, product, order, and inventory data. Here’s a list of the key diagrams PlantUML can generate: Use Case Diagram Purpose: To visualize the system’s functionality and interactions with actors. Usage: Representing system functionalities and how users interact with them. Example: Actors interacting with system use cases. Activity Diagram Purpose: To model the workflow of activities and decision-making paths within a system. Usage: Business process modeling, workflow design, system flow visualization. Example: Visualizing the steps in processing an order. Component Diagram Purpose: To describe the components of a system and their relationships. Usage: Architecture design, service-oriented architecture, microservices. Example: Illustrating how various components interact in a system. State Diagram (State Machine Diagram) Purpose: To model the various states of an object in a system and the transitions between these states. Usage: Systems with complex state transitions, finite state machines. Example: Showing the states of an order during processing. Object Diagram Purpose: To show instances of classes and their relationships at a particular moment. Usage: Snapshot of objects in the system during runtime. Example: Visualizing specific object instances at a given time. Deployment Diagram Purpose: To model the physical deployment of software artifacts on hardware nodes. Usage: Representing the architecture of system deployment, servers, networks, and services. Example: Showing how applications are deployed across servers. Timing Diagram Purpose: To represent changes in state or value over time. Usage: Hardware design, embedded systems, communication protocols. Example: Modeling the timing of signals or data exchange. Communication Diagram (Collaboration Diagram) Purpose: To show the interactions between objects or components and the messages exchanged. Usage: Visualizing communication patterns within systems. Example: Components sending messages to each other. Archimate Diagram Purpose: To represent enterprise architecture layers, relationships, and viewpoints using the Archimate framework. Usage: Enterprise architecture modeling. Example: High-level business and IT system architecture. Mind Map Purpose: To create mind maps for brainstorming and organizing ideas. Usage: Knowledge organization, planning, and structuring concepts. Example: Creating a mind map of system features. Wireframe Diagram Purpose: To design wireframes and user interfaces. Usage: UI/UX design and prototyping. Example: Drawing mockups of application interfaces. Conclusion PlantUML is an extremely versatile tool, supporting a wide variety of diagrams from simple UML class diagrams to complex enterprise architecture and wireframes. Whether you’re designing software, modeling databases, or documenting workflows, PlantUML provides a flexible, code-driven approach to creating diagrams.
