Ilograph diagrams are interactive, multi-perspective diagrams. From one Ilograph, users can view a system from multiple points of view and multiple levels of detail. Whereas existing solutions would require separate, unconnected diagrams to describe a system from different perspectives, Ilograph diagrams treat perspectives as first-class citizens. First-class support for perspectives is one of several Ilograph features that help users better understand their systems; I'll expand on these (and have more on perspectives!) in future posts. For more examples of Ilograph diagrams in action, please see the Ilograph home page.
